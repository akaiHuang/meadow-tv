# 隱私與安全

Meadow TV 由電視 App 與選配的 Mac 中控組成。首頁、天氣與 Podcast 可以獨立使用；連接 Codex 時，請使用自己的帳號，並讓電視與 Mac 位於可信任的私人網路。

## 帳號與配對

Codex 登入在 Mac 的官方授權頁完成。Meadow 不需要你提供帳號密碼、驗證碼或 API key，也不會把 Codex 登入資料傳給電視。影音服務則由各自的 App 管理登入與訂閱。

電視與 Mac 需經過授權配對，連線使用 HTTPS。請勿將中控或 ADB 開放到公用網際網路，並只允許自己信任的裝置連線。

## 哪些資料會被使用

| 功能 | 使用的資料 |
| --- | --- |
| Meadow 文字助理 | 送出的訊息、近期對話，以及完成要求所需的電視狀態，會透過 Mac 上的 Codex 傳送給 OpenAI。 |
| 跨 App 操作 | 啟用無障礙服務後，Meadow 可按任務需要讀取目前介面的可見文字與操作項目，並執行支援的導覽。這些資訊可能提供給 Codex。 |
| 實驗語音 | 按下語音按鈕後才開始收音，音訊與轉錄會傳送給 Codex 語音服務。離開首頁、切換 App 或閒置約三分鐘後停止語音連線。 |
| Podcast 與節目探索 | 搜尋詞與一般連線資訊可能傳送給 Apple Podcasts、節目發布者及影音圖資服務。 |
| 天氣 | 依選擇的城市向 Open-Meteo 查詢，不要求裝置定位權限。 |

App 會保存播放清單、收藏、偏好與配對設定，方便下次使用。Codex 與其他服務的資料處理方式，依各服務及工作區的隱私政策為準。

## 由你決定的權限

- **麥克風：**僅供選配語音使用；不授權仍可使用文字助理。
- **無障礙服務：**供跨 App 導覽與指定遙控器快捷鍵使用，可隨時在電視系統設定關閉。關閉後，Meadow 自身介面與媒體功能仍可使用。
- **本機網路與偵錯：**用於 Mac 與電視連線。完成設定後，可在電視的開發人員選項關閉不再需要的偵錯授權。

部分 App 無法提供可操作的介面資訊。也請避免讓自動操作停留在登入、付款或私人對話頁面；第三方 App 的欄位標記可能不足以遮蔽所有敏感文字。

## 暫停或停止使用

在執行中控的終端機按 **Ctrl-C** 即可停止中控。若不再使用跨 App 操作，可關閉 Meadow 的無障礙服務；預設首頁也可從電視系統設定切回原本的 App。

移除 App 或清除 App 資料會一併刪除電視上的播放清單、收藏、偏好與配對設定，操作前請先確認需要保留的內容。

## 回報問題

請提供 Meadow 版本、電視型號、Android 版本與重現步驟。截圖及錯誤訊息請先移除個人資料；不要在公開 Issue 上傳登入資料、配對資訊、完整日誌或私人對話。

安全問題請優先使用 GitHub 的私密安全回報功能。若專案頁未提供此功能，可先以不含敏感細節的 Issue 詢問聯絡方式。
